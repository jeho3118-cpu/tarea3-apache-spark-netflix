Descripción
Proyecto desarrollado utilizando Apache Spark y PySpark para realizar el procesamiento batch del conjunto de datos Netflix Titles.

Dataset
netflix_titles.csv

Tecnologías utilizadas
Apache Spark
PySpark
Python 3
Ejecución
spark-submit netflix_analysis.py
Funcionalidades

- Lectura de datos desde un archivo CSV.
- Creación de DataFrames con Apache Spark.
- Conteo de películas y series.
- Análisis por clasificación de contenido.
- Identificación de los países con más títulos.
- Identificación de los años con mayor cantidad de contenido.

Resultados

El análisis realizado permitió identificar que Estados Unidos es el país con mayor cantidad de contenido dentro del catálogo de Netflix. Asimismo, los años comprendidos entre 2017 y 2020 presentan el mayor número de títulos disponibles en la plataforma.
